# LearnOOPs 🚀

**LearnOOPs** is a C++ project created to learn, practice, and understand the fundamental concepts of **Object-Oriented Programming (OOP)** in C++.

The repository contains simple examples and implementations designed to make OOP concepts easier to understand through practical coding.

## 📚 Concepts Covered

* Classes and Objects
* Encapsulation
* Abstraction
* Inheritance
* Polymorphism
* Constructors and Destructors
* Access Specifiers
* Function Overloading
* Function Overriding
* Operator Overloading
* Static Members
* Friend Functions
* Virtual Functions
* Abstract Classes
* Multiple Inheritance

## 🛠️ Tech Stack

* **Language:** C++
* **Paradigm:** Object-Oriented Programming
* **Compiler:** GCC / MinGW
* **Editor:** VS Code

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/LearnOOPs.git
```

### 2. Open the project

```bash
cd LearnOOPs
```

### 3. Compile a C++ file

Using g++:

```bash
g++ filename.cpp -o program
```

### 4. Run the program

Windows:

```bash
program.exe
```

Linux/macOS:

```bash
./program
```

## 🎯 Purpose

The main purpose of **LearnOOPs** is to build a strong foundation in C++ Object-Oriented Programming by implementing concepts through small and understandable programs.

This repository can also serve as a quick reference while studying C++ OOP for **college coursework, DSA, interviews, and software development**.

* Build a strong foundation for advanced C++ and DSA
